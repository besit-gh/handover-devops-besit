# Интерактивная учебная платформа

## Что публикуется

GitHub Pages собирает статический сайт из Markdown-материалов репозитория. Исходные файлы остаются главным источником знаний, а генератор создаёт HTML-страницы с общей навигацией.

## Возможности

- Каталог курсов и подготовленных материалов.
- Поиск по названию, курсу и тексту материала.
- Боковая панель с группировкой по курсам.
- Переход к предыдущему и следующему материалу.
- Оглавление, индикатор чтения и оценка времени.
- Локальные отметки прохождения и контрольные критерии.
- Расширенные интерактивные лаборатории Linux.
- Автоматическая сборка и проверка в CI.

## Локальная сборка

Установи зависимость Python Markdown и запусти генератор:

    python3 -m pip install Markdown
    python3 scripts/build_learning_site.py

Результат появится в каталоге `site/`. Прогресс сохраняется в localStorage текущего браузера и не синхронизируется между устройствами. Сайт не выполняет команды на сервере: практику запускай в отдельной безопасной лаборатории.
