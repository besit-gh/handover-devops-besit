## Что означает этот статус

Структура, roadmap, карта зависимостей, стандарт уроков и планы тем уже опубликованы. Указанные числа отражают реально созданные отдельные материалы, а не количество тем в планах. Остальные темы curriculum ещё предстоит раскрыть полноценными уроками по утверждённому стандарту; они не считаются готовыми только потому, что перечислены в README курса.

## Правило дальнейшего наполнения

При добавлении урока:
1. создать отдельный Markdown-файл;
2. добавить ссылку в README соответствующего курса;
3. указать предварительные знания и связи с roadmap;
4. проверить команды, примеры, контрольные вопросы и безопасные условия практики;
5. обновить этот статус.
