# Handover DevOps — путь к самостоятельной инженерной работе

Учебный репозиторий от абсолютных основ до production-эксплуатации, диагностики инцидентов и передачи сервиса другой команде.

## Как пользоваться
1. Начни с [дорожной карты](00-Roadmap/README.md).
2. Изучи [стандарт уроков](00-Roadmap/lesson-standard.md).
3. Следуй [пути обучения](00-Roadmap/learning-path.md) и [карте зависимостей](00-Roadmap/dependency-map.md).
4. Выполняй практику в изолированной среде.
5. Закрепляй навыки сквозными проектами, лабораториями и handover.

## Принципы
- Практический минимум теории с объяснением причин, механизмов и поведения при сбоях.
- Реалистичные примеры с разбором результата и оговорками об упрощениях.
- Безопасность и наблюдаемость — часть инженерной работы.
- Одна технология — один курс; интеграция отрабатывается в сквозных проектах.
- Не считать запуск успешным, пока результат не проверен.
