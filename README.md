# Handover DevOps — путь от новичка до инженера

Учебный репозиторий: последовательный roadmap, практические лабораторные работы и handover-документация для освоения DevOps / Platform Engineering.

## С чего начать

1. Открой [ROADMAP.md](ROADMAP.md) — общий маршрут, порядок технологий и правила организации уроков.
2. Иди по порядку: фундамент → сервисы и доставка → IaC и платформы → наблюдаемость и надёжность → production-практики.
3. Каждая технология будет организована одинаково: **технология → этапы → модули → уроки → текст урока**.
4. Этап считается завершённым после практической проверки навыка, а не после чтения материалов.

Каждая технологическая папка будет иметь собственный `README.md` с prerequisites, этапами, модулями и критериями готовности. Подпапки и уроки добавляются последовательно по мере разработки материалов, чтобы репозиторий не заполнялся пустыми каталогами.

## Принципы

- Объяснения от простого к сложному, без предположения о предварительном опыте.
- Команды и примеры проверяемы; у лабораторных работ есть ожидаемый результат.
- Для каждой важной операции изучаются проверка, диагностика, безопасное изменение и откат.
- Безопасность, мониторинг и документация включены в практику с самого начала.
- Главная цель — уметь эксплуатировать системы и передавать их другому инженеру, а не только знать названия инструментов.
