# Nginx

**Назначение:** Веб-сервер, reverse proxy, TLS, балансировка и диагностика.

## Предварительные знания
Linux, HTTP и DNS.

## План курса
1. Master/worker
2. Конфигурация и location
3. Статика и права
4. proxy_pass и заголовки
5. Upstream и балансировка
6. TLS и кеширование
7. Логи и reload
8. 4xx/5xx/502/504
9. Безопасный релиз

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
