01 / Понять

Три субъекта. Три права.

Система проверяет владельца, группу и остальных. Для файла r читает, w изменяет, x запускает.

* Для изменения записей каталога обычно нужны одновременно w и x.

Покрути биты — увидишь результат

Переключай разрешения; цифра считается как сумма r=4, w=2, x=1.

Владелец

rwx

Группа

r-x

Остальные

---
Символически
rwxr-x---
Восьмерично
750
Запомни: на каталоге x — это проход. Одного r недостаточно, чтобы открыть файл по полному пути.
02 / Применить

Рассчитай chmod

Каждая цифра — сумма нужных битов: r=4, w=2, x=1.

Владелец
6
rw-
Группа
4
r--
Остальные
0
---
Задать весь режим
chmod 640 report.txt
Заменяет обычные биты прав на указанные.
Добавить одно право
chmod g+w report.txt
Добавляет группе запись, сохраняя остальные биты.
Не используй 777 как универсальный фикс. Это выдаёт всем чтение, запись и выполнение и не исправляет отказ на родительском каталоге.
03 / Диагностировать

Permission denied

Проверяй от субъекта к пути. Не меняй права, пока не понял, на каком шаге доступ блокируется.

id
ls -l file
namei -l /path/to/file
getfacl file

Общий каталог

SGID помогает наследовать группу; sticky bit ограничивает удаление чужих записей.

chmod 2775 shared/
chmod +t shared/
Калькулятор umask

Маска ограничивает права новых объектов, а не меняет существующие.
