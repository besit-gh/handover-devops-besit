# Демонстрационный сервис для DevOps-проекта

Это минимальное HTTP-приложение на стандартной библиотеке Python. Оно включено в учебный репозиторий, чтобы можно было реально пройти путь от теста до контейнера и CI, а не только прочитать описание.

## Контракт
- `GET /` — JSON с названием сервиса.
- `GET /health` — HTTP 200 и `{"status":"ok","service":"demo-servicio"}`.
- Неизвестный путь — HTTP 404.
- По умолчанию приложение слушает порт 8080; порт можно изменить переменной `PORT`.

## Локально без Docker

Из каталога `90-Capstone-Projects/demo-servicio`:

```bash
python -m unittest discover -s tests -v
python app.py
```

Во втором терминале:

```bash
curl --fail --show-error http://127.0.0.1:8080/health
curl --fail --show-error http://127.0.0.1:8080/
```

Остановите сервер Ctrl+C.

## Через Docker Compose

```bash
docker compose up --build -d
docker compose ps
curl --fail --show-error http://127.0.0.1:8080/health
docker compose logs --tail 50
docker compose down
```

Порт опубликован только на loopback-интерфейсе, поэтому пример рассчитан на локальную лабораторию.

## CI

Workflow запускает проверку синтаксиса, unit tests, сборку Docker-образа и smoke test реального HTTP endpoint в контейнере. При провале любого обязательного шага job завершается с ошибкой. Для проекта без сторонних библиотек отдельный requirements.txt не нужен.

## Учебные задания
1. Добавьте тест на метод, отличный от GET, и решите, какой ответ должен возвращать сервис.
2. Добавьте структурированное поле версии в ответ, не встраивая секреты.
3. Измените health check на неверный порт и разберите, на каком этапе это обнаруживается.
4. Добавьте проверку форматирования или статический анализ как отдельный quality gate.
5. Измените Dockerfile так, чтобы приложение запускалось не от root, и проверьте пользователя через `docker inspect`.
6. Подготовьте runbook по шаблону `../02-Runbook-and-escalation.md`.

## Границы примера
Это учебный сервис без аутентификации, хранения состояния и production-гарантий. Не публикуйте его в интернете без дополнительного проектирования безопасности, наблюдаемости и эксплуатации.
