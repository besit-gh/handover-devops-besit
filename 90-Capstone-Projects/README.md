# Сквозные проекты

**Назначение:** Интеграция технологий в законченные системы с эксплуатацией и handover.

## Предварительные знания
По мере освоения технологий каждого проекта.

## План курса
1. Linux-сервис с логами
2. HTTP-приложение за Nginx
3. Docker Compose
4. CI с тестами и образом
5. Ansible для сервера
6. Terraform-инфраструктура
7. Kubernetes и Helm
8. Observability
9. Secrets
10. Production-релиз, rollback и восстановление
11. Handover-пакет

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
