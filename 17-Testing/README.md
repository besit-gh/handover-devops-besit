# Тестирование

**Назначение:** Проверка приложений и инфраструктурного кода.

## Предварительные знания
Git, CLI и приложение.

## План курса
1. Пирамида тестирования
2. Unit/integration/end-to-end
3. Фикстуры и детерминированность
4. pytest и API
5. Линтеры и статический анализ
6. Контрактные тесты
7. Smoke tests
8. Quality gates
9. Flaky tests

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
