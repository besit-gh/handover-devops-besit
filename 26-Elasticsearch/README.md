# Elasticsearch

**Назначение:** Поиск и аналитика событий, индексы и эксплуатация кластера.

## Предварительные знания
JSON, HTTP и логи.

## План курса
1. Documents и indices
2. Mappings
3. Inverted index
4. Query DSL
5. Index templates
6. Shards и replicas
7. Ingest pipelines
8. Heap и cluster health
9. Snapshots и restore
10. Медленные запросы

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
