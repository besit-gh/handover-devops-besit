# Документы и индексы Elasticsearch

> Начальный уровень · 30–40 минут · Требуются JSON и HTTP.

Elasticsearch хранит документы, обычно представленные JSON, в индексах. Mapping определяет, как поля интерпретируются и индексируются. Неверный тип поля может усложнить запросы, агрегации и дальнейшее изменение схемы.

## Важные нюансы
- Индекс не равен таблице реляционной базы данных.
- Анализируемые текстовые поля подходят для полнотекстового поиска; keyword часто нужен для точных совпадений и агрегаций.
- Большое количество уникальных полей может привести к проблемам mapping.
- Shards и replicas влияют на распределение, доступность и ресурсы.

В учебном кластере изучи mapping через Kibana или API с разрешённой учётной записью. Не выполняй destructive-запросы к неизвестному индексу.
