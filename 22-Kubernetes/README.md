# Kubernetes

**Назначение:** Оркестрация контейнеров, сеть, storage, безопасность и диагностика.

## Предварительные знания
Docker, YAML, сеть, Linux и HTTP.

## План курса
1. Control plane и worker nodes
2. API server
3. Pods и Deployments
4. Namespaces, labels и selectors
5. Services и DNS
6. ConfigMaps и Secrets
7. Probes
8. Requests и limits
9. PV/PVC
10. RBAC и NetworkPolicy
11. CrashLoopBackOff и OOMKilled

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
