# Docker

**Назначение:** Контейнеризация, образы, сети, тома, Compose и безопасность.

## Предварительные знания
Linux, процессы, файлы и сеть.

## План курса
1. Образы и слои
2. Dockerfile и build context
3. Жизненный цикл контейнера
4. Namespaces и cgroups
5. Сети и volumes
6. Compose, env и secrets
7. Healthcheck и сигналы
8. Многоэтапная сборка
9. Непривилегированный пользователь
10. Логи и rollback

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
