# Dockerfile и контекст сборки

> Начальный → средний уровень · 40–50 минут · Требуются образы и файловая система.

Dockerfile описывает создание образа слоями. Build context — набор файлов, доступный сборке. Если контекст слишком большой, сборка замедляется; если в нём лежат чувствительные файлы, они могут случайно попасть в образ или build cache.

~~~dockerfile
FROM python:3.14-slim
WORKDIR /app
COPY app.py .
USER 10001
CMD ["python", "app.py"]
~~~

Это учебный пример для приложения, которое содержит app.py. Проверь совместимость версии Python; production-образу могут понадобиться закреплённый базовый образ и дополнительные меры hardening.

## .dockerignore
Добавь исключения для .git, локальных виртуальных окружений, кешей, .env и файлов, которые не должны передаваться в контекст. Не храни чувствительные данные в репозитории вообще.

## Практика
Собери образ маленького тестового приложения, проверь слои и убедись, что в build context не попадают личные файлы. Сравни размер контекста до и после .dockerignore.
