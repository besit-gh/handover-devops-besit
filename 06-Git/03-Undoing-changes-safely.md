# Безопасное отменение изменений в Git

> Средний уровень · 40–50 минут · Требуются commits и branches.

## Сначала определи, где находится изменение

~~~bash
git status --short
git diff
git diff --cached
git log --oneline -5
~~~

Эти команды помогают понять, находится ли изменение только в рабочей директории, в индексе или уже в истории.

## Выбор инструмента
- Для опубликованного коммита, который нужно отменить новым коммитом, часто подходит git revert.
- Для незакоммиченного изменения используй адресные средства восстановления после просмотра diff.
- git reset перемещает текущую ссылку и может менять индекс/рабочую директорию в зависимости от режима.
- git clean удаляет неотслеживаемые файлы; сначала обязательно изучи dry-run.

~~~bash
git clean -nd
~~~

Это предварительный просмотр, а не удаление. Не запускай destructive-команды, пока не проверил статус, путь и наличие нужных файлов.

## Практика
Создай временный репозиторий, сделай два коммита и отмени один через revert. Не выполняй упражнение в рабочем репозитории проекта.
