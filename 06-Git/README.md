# Git

**Назначение:** История изменений, ветки, конфликты и командная разработка.

## Предварительные знания
Файлы и CLI.

## План курса
1. Рабочая директория и индекс
2. Коммиты и история
3. Ветки и merge
4. Конфликты и rebase
5. Remote, fetch и push
6. Revert, reset и reflog
7. bisect и теги
8. Секреты в истории
9. Code review workflow

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
