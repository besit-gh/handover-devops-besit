# Ветки Git и разрешение конфликтов

> Начальный уровень · 35–45 минут · Требуются рабочая директория, индекс и коммиты.

## Модель
Ветка — подвижная ссылка на коммит. Ветки позволяют изолировать работу, а merge объединяет истории. Конфликт возникает, когда Git не может автоматически определить, как совместить изменения.

## Безопасная практика
В учебном репозитории создай ветку, измени одну строку и зафиксируй коммит. Затем создай вторую ветку от общего предка и измени ту же строку иначе. При слиянии Git может попросить разрешить конфликт.

~~~bash
git status
git diff
git log --oneline --graph --all
~~~

После редактирования конфликтного файла удали маркеры конфликтов, оставь правильный результат и проверь diff. Затем добавь файл в индекс и заверши merge-коммит, если Git его требует.

## Не переписывай историю вслепую
Rebase меняет базу коммитов и может переписать их идентификаторы. Перед reset или rebase проверь статус и историю; не применяй force push к общей ветке без согласованного процесса.
