# Vault

**Назначение:** Секреты, identity, policies, динамические учётные данные и ротация.

## Предварительные знания
Identity, TLS и политики доступа.

## План курса
1. Trust boundary
2. Authentication methods
3. Policies и least privilege
4. KV engine
5. Leases
6. Dynamic database secrets
7. PKI engine
8. Аудит и ротация
9. Backup
10. CI/CD и Kubernetes auth

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
