# Первый pipeline Logstash

> Начальный уровень · 30–40 минут · Требуются JSON и модель логов.

Pipeline Logstash состоит из input, filter и output. Input принимает события, filter преобразует поля, output отправляет результат в целевую систему.

~~~text
Источник → Input → Filter → Output → Хранилище
~~~

Начинай с минимального pipeline и добавляй фильтры по одному. Для каждого преобразования подготовь входное событие и ожидаемую структуру выхода. Так проще отличить ошибку парсинга от проблемы доставки.

## Риски
- Неправильный grok-шаблон оставляет поля нераспознанными.
- Дорогие фильтры повышают задержку.
- Недоступный output создаёт очередь или ошибки повторной доставки.
- Credentials нельзя коммитить в открытом виде.
