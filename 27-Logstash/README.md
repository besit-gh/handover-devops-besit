# Logstash

**Назначение:** Приём, преобразование и маршрутизация событий.

## Предварительные знания
JSON и Elasticsearch.

## План курса
1. Inputs, filters и outputs
2. События и поля
3. Grok и dissect
4. Date и mutate
5. Conditional routing
6. Persistent queue
7. Backpressure
8. Ошибки парсинга
9. Мониторинг доставки

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
