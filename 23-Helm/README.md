# Helm

**Назначение:** Charts, values, шаблоны и релизы Kubernetes-приложений.

## Предварительные знания
Kubernetes и YAML.

## План курса
1. Chart и release
2. Структура chart
3. values
4. Шаблоны и функции
5. Условия и циклы
6. Зависимости
7. install и upgrade
8. rollback и history
9. Lint и render
10. Безопасные defaults

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
