# Helm chart, values и рендеринг

> Начальный уровень · 35–45 минут · Требуются Kubernetes и YAML.

Chart — пакет шаблонов и метаданных Kubernetes-ресурсов. Values предоставляют параметры, а Helm рендерит шаблоны в манифесты. Перед установкой полезно проверять результат рендеринга, а не только исходный шаблон.

~~~bash
helm lint ./my-chart
helm template demo ./my-chart -f values.yaml
~~~

Первая команда выполняет базовые проверки chart. Вторая показывает сгенерированные манифесты без установки релиза.

Проверь уникальность имён ресурсов, безопасные значения по умолчанию, отсутствие секретов в открытом виде и соответствие API-версиям целевого кластера.
