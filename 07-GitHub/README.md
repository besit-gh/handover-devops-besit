# GitHub

**Назначение:** Репозитории, pull request, review, permissions и Actions.

## Предварительные знания
Git и аутентификация.

## План курса
1. Репозитории и README
2. SSH, tokens и permissions
3. Issues
4. Pull request и review
5. Защита веток и CODEOWNERS
6. Actions workflow
7. Runners, secrets и artifacts
8. Supply-chain security
9. Диагностика CI

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
