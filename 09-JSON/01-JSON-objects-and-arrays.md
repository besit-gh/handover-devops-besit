# JSON: объекты и массивы

> Начальный уровень · 25–35 минут · Требуются типы данных и файлы.

JSON поддерживает объекты, массивы, строки, числа, boolean и null. Объект хранит пары ключ-значение; массив — упорядоченную последовательность элементов. Комментарии стандартом JSON не предусмотрены.

~~~json
{
  "service": "demo-api",
  "replicas": 2,
  "enabled": true,
  "ports": [8080, 8081]
}
~~~

Если установлен jq:

~~~bash
jq '.service, .ports[]' config.json
jq empty config.json
~~~

Первая команда извлекает имя сервиса и каждый порт. Вторая проверяет синтаксис без вывода данных при успехе. Валидность синтаксиса не доказывает, что структура соответствует ожиданиям приложения.

## Типичные ошибки
Лишняя запятая, одинарные кавычки вокруг строк, неверный тип поля, отсутствующее обязательное поле или неожиданный null.
