# Terraform: безопасный жизненный цикл инфраструктуры

## Результат
Планировать изменение инфраструктуры с review, ограничением blast radius, контролем состояния и проверяемым восстановлением.

## Предварительные знания
[Plan и apply](./01-Plan-and-apply.md), [State и drift](./02-State-and-drift.md), [Модули и проверка plan](./03-Modules-and-plan-review.md).

## 1. Сначала выясните, что будет изменено
Рабочий цикл:
```bash
terraform fmt -check -recursive
terraform validate
terraform plan -out=tfplan
terraform show tfplan
```

Перед применением объясните каждое создание, изменение, замену и удаление. Проверьте, не будет ли заменён ресурс с данными, публичным адресом, сетевыми правилами или внешней зависимостью. Сохранённый plan может содержать чувствительные значения; ограничивайте доступ к файлу и артефактам.

## 2. Состояние — часть системы
State связывает конфигурацию с реальными объектами. Не редактируйте state вручную и не храните общий state в Git. Для командной работы нужен поддерживаемый remote backend с блокировкой и контролем доступа. Ручное изменение облачного ресурса может вызвать drift, который нужно исследовать до следующего apply.

## 3. Ограничивайте blast radius
Разделяйте окружения и независимые компоненты там, где это уменьшает область возможного отказа. Не создавайте один огромный state для всех систем без явной причины. Ограничивайте права provider credentials и используйте отдельные учебные аккаунты/проекты с бюджетом.

## 4. Практика без затрат
В локальной лаборатории используйте модуль с локальными ресурсами либо проверяйте план без apply. Измените один входной параметр и сравните план. Объясните, какие изменения безопасны, какие требуют обслуживания и какие разрушительны. Не применяйте учебный план к рабочему облачному аккаунту.

## 5. Перед применением
- подтверждена целевая учётная запись и окружение;
- state актуален и не занят другой операцией;
- plan относится к текущей версии кода;
- все замены и удаления объяснены;
- есть стратегия восстановления и оценка стоимости;
- логирование и артефакты не раскрывают секреты.
