# Terraform state и drift

> Средний уровень · 40–50 минут · Требуются plan/apply и Git.

## Зачем нужен state
Terraform state связывает адреса ресурсов в конфигурации с реальными объектами инфраструктуры и хранит сведения, необходимые для планирования следующих изменений. State может содержать чувствительные данные, поэтому его нужно защищать и контролировать доступ.

## Drift
Drift — расхождение между описанной конфигурацией и фактическим состоянием, возникшее, например, после ручного изменения ресурса вне Terraform.

## Безопасная диагностика
1. Убедись, что выбран правильный аккаунт, workspace и backend.
2. Получи план и изучи предполагаемые изменения.
3. Разберись, почему фактическое состояние отличается.
4. Реши, нужно ли обновить конфигурацию, импортировать объект или восстановить ожидаемое состояние.
5. Не применяй план с неожиданным удалением или заменой ресурсов.

Remote backend с блокировкой помогает избежать одновременного изменения state несколькими исполнителями, но не отменяет code review и проверку плана.
