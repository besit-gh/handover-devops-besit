# Terraform

**Назначение:** Infrastructure as Code, state, modules и безопасные изменения.

## Предварительные знания
Сети, Git, облачная модель и IAM.

## План курса
1. Providers и resources
2. Variables и outputs
3. Граф зависимостей
4. Plan и apply
5. State и locking
6. Remote backend
7. Modules и workspaces
8. Import и drift
9. Разрушительные изменения
10. Тестирование модулей

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
