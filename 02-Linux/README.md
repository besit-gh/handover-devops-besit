# Linux

**Назначение:** Администрирование, диагностика, хранение, сеть, безопасность и автоматизация.

## Предварительные знания
Foundations.

## План курса
1. Файловая система и утилиты
2. Пользователи, группы и права
3. ACL, umask и sudo
4. Процессы, сигналы и /proc
5. systemd и journalctl
6. Пакеты и обновления
7. Сеть и сокеты
8. Диски, mount, fstab и swap
9. CPU, память и inode
10. SSH и hardening
11. cron и timers
12. Проект сопровождения

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.

## Публикация интерактивных уроков
Исходники интерактивных страниц находятся в `web-lessons/` и запускаются локально без сборки и внешних библиотек. Workflow [linux-permissions-pages.yml](../.github/workflows/linux-permissions-pages.yml) проверяет обе страницы и публикует их по прямым путям; корень Pages по-прежнему показывает урок о правах доступа. Публикация запускается при изменениях в ветке `features`; источник GitHub Pages в настройках репозитория должен быть **GitHub Actions**.
