# Файловая система Linux и навигация

> **Уровень:** начальный · **Время:** 30–45 минут · **Предварительные знания:** Foundations — терминал и пути.

## Модель

В Linux единая иерархия начинается от корня /. Каталоги /etc, /var, /home и /usr имеют разные назначения. Структура зависит от дистрибутива и установленного ПО.

## Навигация

~~~bash
pwd
ls -lah
cd /tmp
pwd
cd ~
printf '%s\n' "$HOME"
~~~

pwd показывает текущий каталог, ls — содержимое, cd меняет каталог, ~ и HOME обычно указывают на домашний каталог пользователя.

## Безопасная работа с файлами

~~~bash
mkdir -p ~/devops-lab/files
cd ~/devops-lab/files
printf 'first line\nsecond line\n' > sample.txt
cat sample.txt
cp sample.txt copy.txt
mv copy.txt renamed.txt
ls -l
~~~

Команды работают внутри учебного каталога. Оператор > перезаписывает файл; >> добавляет данные. Проверяй путь перед командами удаления или перезаписи.

## Важные каталоги

- /etc — конфигурация системы и служб.
- /var/log — многие системные и прикладные журналы.
- /home — домашние каталоги.
- /tmp — временные данные; правила очистки зависят от системы.
- /usr/bin — множество исполняемых пользовательских программ.
- /proc — интерфейс к сведениям ядра, а не обычное хранилище.

## Диагностика

~~~bash
file sample.txt
stat sample.txt
df -h .
du -sh .
~~~

file определяет тип по содержимому, stat показывает метаданные, df — использование файловой системы, du — объём каталога. Не путай эти показатели.
