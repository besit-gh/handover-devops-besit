# Пользователи, группы и права доступа

> Начальный уровень · 40–50 минут · Требуются файловая система и базовые команды Linux.

**Интерактивная лаборатория:** [открыть веб-урок: права доступа Linux](../../web-lessons/linux-permissions/). В лаборатории есть матрица rwx, калькулятор chmod, блок-схемы диагностики, симулятор терминала, сценарии, контроль знаний и дополнительные источники. Для локального запуска открой `web-lessons/linux-permissions/index.html` в браузере.

Процесс выполняется с идентификаторами пользователя и групп. Для обычных файлов права read/write/execute имеют отдельные биты для владельца, группы и остальных. Для каталогов execute означает возможность прохода/поиска по пути.

~~~bash
id
ls -ld .
stat notes.txt
namei -l /путь/к/файлу
~~~

namei -l помогает увидеть права каждого компонента пути. Даже если сам файл доступен, отсутствие права прохода на родительском каталоге может помешать обратиться к нему.

## Практика в лаборатории

~~~bash
mkdir -p ~/devops-lab/access
printf 'training\n' > ~/devops-lab/access/note.txt
chmod 640 ~/devops-lab/access/note.txt
chmod 750 ~/devops-lab/access
stat ~/devops-lab/access/note.txt
~~~

Выполняй команды только в учебном каталоге, не в системных директориях.

## Диагностика
1. Проверь пользователя и группы через id.
2. Проверь каждый компонент пути.
3. Уточни ACL и mount options, если обычные права не объясняют отказ.
4. Только после этого меняй минимально необходимое право.
