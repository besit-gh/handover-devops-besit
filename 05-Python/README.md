# Python для DevOps

**Назначение:** Автоматизация, API, данные, процессы и тесты.

## Предварительные знания
CLI и основы программирования.

## План курса
1. Типы и функции
2. Модули и виртуальные окружения
3. Исключения
4. Файлы и pathlib
5. subprocess
6. Переменные окружения и logging
7. JSON, YAML и HTTP API
8. Таймауты и повторы
9. pytest и моки
10. CLI-проект

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
