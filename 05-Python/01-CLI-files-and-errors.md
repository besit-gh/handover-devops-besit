# Python: CLI, файлы и обработка ошибок

> Начальный уровень · 35–45 минут · Требуются командная строка и базовая логика программирования.

## Цель
Написать небольшой скрипт, который принимает путь, проверяет файл, читает данные и корректно сообщает об ошибках.

## Пример

~~~python
from pathlib import Path
import argparse
import sys

parser = argparse.ArgumentParser(description="Подсчитать строки в файле")
parser.add_argument("path", type=Path)
args = parser.parse_args()

try:
    with args.path.open(encoding="utf-8") as file:
        count = sum(1 for _ in file)
except OSError as error:
    print(f"Не удалось прочитать файл: {error}", file=sys.stderr)
    raise SystemExit(1)

print(count)
~~~

Сохрани код в count_lines.py и запусти его с путём к существующему текстовому файлу, затем с несуществующим путём. Скрипт не меняет файлы: он только читает и считает строки.

## Разбор

- argparse обрабатывает аргументы CLI и показывает справку.
- pathlib.Path представляет путь независимо от ручной конкатенации строк.
- with закрывает файл после чтения, в том числе при ошибке.
- OSError перехватывает типовые ошибки доступа и открытия.
- Диагностика идёт в stderr, а код завершения сообщает вызывающему процессу об ошибке.

Не перехватывай все исключения без необходимости: слишком широкий except может скрыть ошибку в самом коде.
