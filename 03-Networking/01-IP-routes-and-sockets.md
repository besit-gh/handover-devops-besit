# IP-адреса, маршруты и сокеты

> **Уровень:** начальный · **Время:** 35–45 минут · **Предварительные знания:** основы ОС и терминала.

## Цели

Понимать назначение IP-адреса, маршрута и порта; собирать первичные сетевые факты; не путать отсутствие ответа с отсутствием маршрута.

## Модель

IP-адрес идентифицирует сетевой интерфейс в IP-сети. Маршрут подсказывает системе, через какой интерфейс и следующий узел отправить пакет. Порт помогает определить конечную точку транспортного соединения на узле. Эти понятия связаны, но не взаимозаменяемы.

## Сбор фактов в Linux

~~~bash
ip -brief address
ip route
ip route get 1.1.1.1
ss -lnt
~~~

- ip -brief address показывает интерфейсы и адреса.
- ip route показывает таблицу маршрутизации.
- ip route get показывает выбранный маршрут к конкретному адресу.
- ss -lnt показывает TCP-сокеты в состоянии прослушивания.

Вывод зависит от WSL, VPN, контейнеров и локальной сети. Не копируй адреса из примера как будто они обязаны совпадать с твоей системой.

## Как рассуждать о недоступности

Если клиент не может подключиться к сервису, последовательно проверь: имя разрешается в ожидаемый адрес; маршрут к адресу существует; соединение проходит до нужного узла; порт действительно слушается; firewall не блокирует трафик; приложение отвечает корректно.

Успешный ping не доказывает доступность TCP-порта: ICMP и TCP — разные протоколы, а ICMP может фильтроваться.
