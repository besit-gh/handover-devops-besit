# Лаборатории и инциденты

**Назначение:** Изолированные сценарии диагностики и восстановления.

## Предварительные знания
Выполнять только в тестовой среде и по указанным предусловиям.

## План курса
1. Неправильные права
2. Служба не запускается
3. Диск и inode заполнены
4. Сетевой сбой
5. Ошибка reverse proxy
6. Контейнер завершился
7. CI не проходит тесты
8. Неудачный релиз
9. Pod CrashLoopBackOff
10. Пропавшие метрики и логи
11. Секрет недоступен
12. Отчёт об инциденте

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
