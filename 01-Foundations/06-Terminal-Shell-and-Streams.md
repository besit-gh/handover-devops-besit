# Терминал, shell и потоки данных

> **Уровень:** начальный · **Время:** 30–40 минут · **Предварительные знания:** базовая работа с ОС.

## Терминал и shell — не одно и то же

Терминал предоставляет интерфейс ввода-вывода. Shell — программа, которая разбирает команду, выполняет подстановки, запускает процессы и управляет перенаправлениями. В Ubuntu обычно используется Bash.

## Команда, аргументы и опции

~~~bash
ls -lah /var/log
~~~

Здесь ls — команда, -lah — набор опций, /var/log — аргумент. Опции определяют режим работы, аргументы указывают, с чем работать.

## Три стандартных потока

- **stdin (0):** входные данные.
- **stdout (1):** обычный результат.
- **stderr (2):** диагностические сообщения.

~~~bash
printf 'alpha\nbeta\n' > sample.txt
grep 'beta' sample.txt
grep 'missing' sample.txt
~~~

Первая команда создаёт тестовый файл. Вторая выводит найденную строку. Третья не находит совпадение и обычно возвращает код 1 — это не ошибка синтаксиса grep, а отсутствие совпадений.

## Перенаправление и pipeline

~~~bash
printf 'alpha\nbeta\n' | grep beta
command-that-does-not-exist 2> error.log
~~~

Pipeline передаёт stdout одной команды в stdin другой. Перенаправление 2> сохраняет stderr в файл. Будь осторожен с оператором >: он может перезаписать существующий файл.

## Коды завершения

~~~bash
grep beta sample.txt
echo "$?"
~~~

Код 0 обычно означает успех, ненулевой код — отсутствие совпадения или ошибку, в зависимости от команды. Не интерпретируй код без документации конкретной утилиты.

## Практика

1. Создай файл с тремя строками и найди одну из них через grep.
2. Направь обычный вывод в файл, а ошибку — в отдельный файл.
3. Проверь коды завершения успешного и неуспешного поиска.
4. Объясни разницу между отсутствием совпадения и ошибкой запуска команды.
