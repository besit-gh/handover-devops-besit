# CPU, RAM, диск и сетевой интерфейс

> **Уровень:** начальный · **Время:** 25–35 минут · **Предварительные знания:** «Что такое операционная система».

## Роли ресурсов
- **CPU:** выполняет инструкции потоков.
- **RAM:** хранит данные и код, используемые в данный момент.
- **Диск:** долговременно хранит файлы и данные.
- **Сетевой интерфейс:** отправляет и принимает сетевые кадры и пакеты.

Сервис может медленно отвечать из-за CPU, ждать диск или исчерпать RAM. Симптом «медленно» сам по себе не указывает на причину.

## Первичная диагностика
~~~bash
uptime
free -h
df -h
df -i
ip -brief address
~~~
- uptime показывает время работы и усреднённую нагрузку.
- free -h показывает память и swap; учитывай доступную память и кеши, а не только колонку free.
- df -h показывает заполнение файловых систем.
- df -i показывает расход inode.
- ip -brief address показывает интерфейсы и адреса.

## Метод
Сформулируй проверяемую гипотезу, например «исчерпана память», и найди измерение, которое может подтвердить или опровергнуть её. Не делай вывод по одному числу.
