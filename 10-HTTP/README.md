# HTTP

**Назначение:** Протокол HTTP и диагностика приложений и прокси.

## Предварительные знания
TCP/IP, порты и клиент-сервер.

## План курса
1. Запрос и ответ
2. Методы и семантика
3. Коды состояния
4. Заголовки и тело
5. Cookies и сессии
6. Кеширование
7. Аутентификация и CORS
8. curl и таймауты
9. HTTP-версии
10. Инцидент HTTP

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
