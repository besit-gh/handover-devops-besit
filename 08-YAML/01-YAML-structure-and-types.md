# Структура YAML и типы данных

> Начальный уровень · 25–35 минут · Требуются файлы и базовые типы данных.

YAML представляет данные в виде скаляров, списков и отображений. Вложенность определяется отступами, поэтому случайное изменение отступа меняет структуру документа или делает его некорректным.

~~~yaml
service:
  name: demo-api
  replicas: 2
  enabled: true
  ports:
    - 8080
    - 8081
~~~

Здесь service — отображение, ports — список чисел. Значение 2 является числом, true — логическим значением. Для неоднозначных строк используй явные кавычки.

## Практика
Сохрани пример в файл и проверь его парсером используемого инструмента. Затем намеренно сдвинь отступ и сравни ошибку. Валидный YAML ещё не гарантирует, что конфигурация соответствует схеме приложения.

## Типичные ошибки
- Непоследовательные отступы.
- Значение интерпретируется не как ожидаемый тип.
- Дублирующиеся ключи.
- Документ синтаксически корректен, но не соответствует схеме.
