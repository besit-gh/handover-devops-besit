# База данных, схема и первый SQL-запрос

> Начальный уровень · 35–45 минут · Требуются основы данных и клиент-сервер.

PostgreSQL обслуживает подключения к базам данных. Внутри базы объекты организуются по схемам; таблицы содержат строки и столбцы. Роли определяют идентичность и права доступа.

~~~sql
CREATE TABLE services (
    id integer GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    name text NOT NULL,
    enabled boolean NOT NULL DEFAULT true
);
INSERT INTO services (name) VALUES ('api');
SELECT id, name, enabled FROM services;
~~~

Выполняй пример только в отдельной учебной базе. CREATE TABLE создаёт структуру; INSERT добавляет строку; SELECT читает результат. PRIMARY KEY задаёт уникальный идентификатор, NOT NULL запрещает отсутствие значения.

## Эксплуатационные замечания
- Не выполняй миграции в production без плана, проверки и согласованного окна.
- Не выдавай приложению административную роль без необходимости.
- Проверяй backup восстановлением.
- Для медленных запросов изучай план выполнения, а не добавляй индексы наугад.
