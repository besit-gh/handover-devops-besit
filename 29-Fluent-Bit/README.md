# Fluent Bit

**Назначение:** Лёгкий сборщик логов и телеметрии.

## Предварительные знания
Linux, файлы, JSON и сеть.

## План курса
1. Inputs и parsers
2. Filters и outputs
3. Tail и позиция чтения
4. Структурированные логи
5. Buffering
6. Backpressure
7. Kubernetes metadata
8. TLS
9. Retries
10. Недоставленные события

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
