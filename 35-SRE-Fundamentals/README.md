# SRE Fundamentals

**Назначение:** SLI/SLO, error budgets, алертинг, capacity и надёжность.

## Предварительные знания
Мониторинг, инциденты и эксплуатация.

## План курса
1. SLI/SLO/SLA
2. Error budget
3. Latency, traffic, errors, saturation
4. Alerting по симптомам
5. Снижение шума
6. Capacity planning
7. Нагрузочное тестирование
8. Graceful degradation
9. Toil
10. Blameless postmortem

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
