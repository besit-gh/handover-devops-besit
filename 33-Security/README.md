# Безопасность DevOps

**Назначение:** Защита систем, цепочки поставки, identity, сетей, контейнеров и секретов.

## Предварительные знания
Linux, сети, Git и контейнеры.

## План курса
1. Модель угроз
2. Least privilege
3. IAM
4. Patch management
5. Секреты и ротация
6. SBOM и зависимости
7. Подпись артефактов
8. Сканирование образов и IaC
9. Linux hardening
10. Реагирование на инциденты

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
