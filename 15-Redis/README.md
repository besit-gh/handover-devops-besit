# Redis

**Назначение:** Структуры данных, кеширование, TTL и отказоустойчивость.

## Предварительные знания
Linux, сеть и структуры данных.

## План курса
1. Ключи и типы данных
2. TTL и eviction
3. Атомарность
4. RDB и AOF
5. Память
6. Репликация и Sentinel
7. Cluster и ACL
8. Кеш-инвалидация
9. Cache stampede
10. Диагностика latency

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
