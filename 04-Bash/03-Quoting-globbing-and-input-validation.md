# Кавычки, globbing и проверка аргументов Bash

> Начальный → средний уровень · 35–45 минут · Требуются первый Bash-скрипт и переменные.

Без кавычек shell может выполнить разделение слов и раскрытие шаблонов файлов. Поэтому путь с пробелами или символом * может превратиться в несколько аргументов или набор имён файлов.

~~~bash
path="$HOME/devops lab/*.txt"
printf 'Один аргумент: <%s>\n' "$path"
printf 'Число аргументов: %s\n' "$#"
~~~

Кавычки вокруг "$path" сохраняют значение как один аргумент. Они не делают ввод автоматически безопасным для всех контекстов: SQL, регулярные выражения и другие интерпретаторы имеют свои правила.

## Проверка аргументов
Проверяй количество, тип и существование входных данных до изменения состояния. Для путей используй тесты -f для обычного файла и -d для каталога. Избегай динамического исполнения команд, собранных из пользовательских строк.

## Практика
Создай файл с пробелом в имени. Передай путь скрипту как один аргумент, затем убери кавычки в копии скрипта и сравни поведение. Все эксперименты выполняй в каталоге лаборатории.
