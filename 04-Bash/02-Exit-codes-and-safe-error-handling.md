# Коды завершения и обработка ошибок в Bash

> Начальный → средний уровень · 35–45 минут · Требуются первый Bash-скрипт и потоки.

## Модель
Каждая завершившаяся команда возвращает код. Обычно 0 означает успех, ненулевой код — особый результат или ошибку. Значение определяется конкретной программой: например, grep возвращает 1, если совпадений нет, и это может быть ожидаемым исходом.

## Явная проверка

~~~bash
if grep -q 'ready' status.txt; then
  echo "Состояние ready найдено"
else
  rc=$?
  echo "Совпадение не найдено или возникла ошибка; код=$rc" >&2
fi
~~~

Если нужно различать «нет совпадения» и реальную ошибку grep, проверяй коды согласно документации команды. В общем случае не все ненулевые коды означают одно и то же.

## Ограничения set -e
set -e может помочь заметить некоторые необработанные ошибки, но его поведение зависит от контекста: условия, списки команд, pipeline и подстановки имеют нюансы. Не считай его полноценной системой обработки ошибок.

## Практика
Создай файл с ожидаемой строкой и без неё. Проверь оба сценария, затем проверь поведение, когда файл отсутствует. Объясни разницу между бизнес-условием «нет совпадения» и технической ошибкой чтения.
