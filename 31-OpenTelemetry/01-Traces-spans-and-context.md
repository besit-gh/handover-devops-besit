# Traces, spans и распространение контекста

> Начальный уровень · 35–45 минут · Требуются HTTP и распределённые приложения.

Trace представляет путь одной операции через систему. Span описывает отдельную операцию и может иметь родительский span. Контекст передаётся между сервисами, чтобы связывать spans в одну трассировку.

Если HTTP-запрос медленный, trace может показать, что задержка возникла при обращении к базе или внешнему API. Польза зависит от корректного инструментирования и распространения контекста.

## Ограничения
- Sampling может сохранять не каждую трассировку.
- Высокая cardinality атрибутов увеличивает стоимость хранения.
- В spans нельзя помещать пароли и токены.
- Trace не заменяет метрики общего состояния и подробные логи.
