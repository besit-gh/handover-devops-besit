# OpenTelemetry

**Назначение:** Traces, metrics, logs и распространение контекста.

## Предварительные знания
HTTP и распределённые приложения.

## План курса
1. Signals
2. Spans
3. Context propagation
4. Semantic conventions
5. SDK и instrumentation
6. Collector
7. Sampling
8. Resource attributes
9. Связь trace ID с логами
10. Диагностика пропавших spans

## Критерий готовности
Уметь объяснить основные механизмы, выполнить типовые операции, проверить результат, диагностировать характерные ошибки и безопасно описать изменения. Практические навыки закрепляются лабораторными заданиями.
